        Audit Report & Checklist

        Honest note: automated tools (axe, Lighthouse, WAVE) catch only a portion of WCAG issues (commonly estimated around 30–40%). Manual testing is required.

        Test-method guide
        • Keyboard only: Tab/Shift+Tab, Enter, Space, arrows, Esc. Check order, focus visibility, traps.
        • Screen readers: NVDA with Firefox/Chrome, VoiceOver with Safari, TalkBack on Android.
        • Zoom: browser 200% and 400%, 320px width, OS magnifier.
        • Contrast: WebAIM checker, browser DevTools, this lab.
        • Automated: axe DevTools, Lighthouse, WAVE. Treat as a starting point.

        A11y Lab is a learning aid. It does not replace testing with real assistive technology.
